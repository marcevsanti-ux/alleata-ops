⏱️ SLA Operaciones / Logística

SLA Operaciones = días entre "En Proceso" (arranca configuración) y "Pre-Colecta" (lista para despachar). SLA Logística = días entre "Pre-Colecta" y "Exitoso" (entregada). Calculado acá a partir de las fechas ya sincronizadas desde Salesforce, y cruzado contra el valor que el backend ya guarda (columna "Diferencia") para detectar si quedó desactualizado — no compara todavía contra el campo de fórmula nativo de Salesforce (ese campo aún no está sincronizado a esta base).
